# LeiaSRBridge 0.9.1

面向兼容 BOE / DepthTransformerPlus 底层方案的裸眼 3D 显示器，将 LeiaSR SDK 1.34.10 x64 客户端的左右眼图像接入原生 3D 输出。

- 产品统一更名为 LeiaSRBridge，包含主程序、交织测试、界面、图标、日志及发行包。
- 保留既有 settings.ini、游戏列表、免列表接入和自启动配置；旧自启动入口可迁移。
- 支持 DX12 与 Odyssey 使用的旧版 DX11/DX12 接口、双眼位置及头部旋转、无人脸默认眼位回退。
- 提供原生 LeiaSR 追踪预览、全局眼位补偿和预测、开机自启动与 Odyssey Hub 兼容启动。
- 泰坦军团 M27E6V-3D 已有实机验证；雷神、AOC 本次分析的软件方案兼容，实体屏待验证；ViewX 暂不支持。AOC 新增的可选摄像头 ROI 增强尚未集成。

## 安装与升级

下载 LeiaSRBridge-0.9.1-win64.zip 完整包。先退出游戏、桥接、交织测试及占用摄像头的原厂程序，再解压到可写目录。升级时覆盖原目录，保留自己的 settings.ini 和 games.txt。不要混用旧 DLL。目录改变后重新登记免列表接入和自启动。

本次上传的是已有的原始 0.9.1 构建，未重新编译或改写；包内历史文档可能早于 AOC 分析，最新兼容性说明见仓库 README。此版本尚不含程序内检查更新入口。
