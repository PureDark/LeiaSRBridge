# LeiaSRBridge 0.9.2

## 程序内更新

- 新增“更多 → 检查更新”，查询 GitHub 最新正式 Release，显示版本说明和下载进度。
- 完整包下载后校验 GitHub SHA-256、ZIP 路径、文件清单和逐文件哈希，再允许安装。
- 点击“安装并重启”后，助手等待桥接正常退出，在原目录更新；保留设置、游戏列表、日志及显示器标定，已有免列表接入和自启动路径继续有效。
- 发现文件占用时停止更新；覆盖失败尝试回滚。更新完成后自动重启。请先退出游戏、交织测试和 Odyssey Hub。
- 更新检查使用匿名 HTTPS，不读取或保存令牌。私有仓库、没有 Release、限流、网络失败和校验失败会显示具体信息；仓库公开后无需修改设置。
- 发行包补充 AOC 软件兼容性分析。

## 首次升级

0.9.1 及更早版本没有更新入口，请先手动下载 LeiaSRBridge-0.9.2-win64.zip，退出桥接及游戏后完整覆盖原目录，保留 settings.ini / games.txt。之后可在程序内检查、下载和安装更新。

## 验证与边界

27 项离线测试通过，包含真实 WebView2 界面、Windows PowerShell 5.1 更新器、损坏/异常 ZIP 拒绝、文件锁、中途失败回滚、中文路径、等待原进程退出及替换后重启。100 个转发导出、5 个客户端导入、11 组二进制/PDB 配对通过。匿名访问当前私有仓库实测返回 HTTP 404；成功下载路径使用隔离数据验证，尚未对公开仓库执行真实跨版本升级。

本版未修改 BOE 追踪、交织和 MCU 标定；显示器/游戏支持边界见 README。
