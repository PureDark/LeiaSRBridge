原因明确：转接器启动时检测到 **`DepthTransformerPlus.exe` 仍在运行**，因此主动停止设备初始化。此时还没有尝试读取校准或启动眼追。

按这个顺序操作：

1. **完全退出 DepthTransformerPlus**，在任务管理器确认 `DepthTransformerPlus.exe` 已消失；仅关闭窗口可能仍留在后台。
2. 在转接器中点击 **“退出转接器”**，然后重新运行。当前版本初始化失败后不会自动重试。
3. 等待“校准：可用、眼位：可用”后，再启动游戏。

不需要先开启原厂的 2D 转 3D。转接器会自行初始化设备和眼追，但仍依赖已安装的原厂组件。

日志里的“后台已启动”只表示后台程序已运行，**不代表设备初始化成功**。如果重启后仍失败，把新增日志发来。
