## 标定与几何

`sub_180038D30` 和汇编确认 E1/E2 为 `fx,fy,cx,cy,k1,k2,p1,p2,k3`。
`sub_180039070` 确认 E3 为 `f,cx,cy,baseline,rectification_rvec0[3],rectification_rvec1[3]`，两个旋转向量经 Rodrigues 转为校正矩阵。第四参数只改变 baseline 符号，重建使用绝对基线与视差幅值。

沿用原厂 `sub_1800AFB70` 的坐标约定：校正后两相机射线的中点，X/Y取负，Z朝向观看者；不额外加半个基线。然后使用与交织相同的 wholeMat 转屏幕坐标。求解不使用位置预测或全局水平补偿。

头部 X 轴取双眼连线，Y 轴取口部中点到眼部中点并正交化，Z 为叉积。检查眼距、眼口距离、嘴宽、双目极线误差、正深度、鼻部位置和正交矩阵；拒绝侧脸退化或不可信点。它是三轴面部几何估计，不是经过个人标定的解剖学头姿，表情/脸型可能造成静态偏差；没有采用点序存疑的原厂九点 PnP 模板。

## 发布与失效

- BOE IPC v2：保留168字节公开原始输出，并新增20个浮点面部坐标及独立有效位。
- Broker IPC v3：独立旋转矩阵、序号和观察时间。
- Head / HeadPose：矩阵转换成 Rodrigues 旋转向量（弧度），匹配已核对的 Leia 行为。窗口采用 ZYX 分解显示俯仰/左右/侧倾角度，便于实机验证。
- 姿态有效时耳位为中心 + R×(±70,0,0)。无姿态但有双眼时保留旧的眼轴估算耳位。
- 不重新计算重复 SDK 序号，不靠后台轮询续期。缺失、坏点、过期、默认或保持眼位时 orientation 无效，光学显示继续沿用原回退。进程创建时间参与缓存身份，避免重启序号碰撞。

## 验证与限制

`HeadPoseSmoke` 使用 OpenCV 独立生成带畸变/校正的像点，三轴 ±40°、450/650/900 mm 共81组；浮点往返最大数值角误差约0.000972°，不是传感器精度指标。另覆盖 wholeMat 次序、补偿不影响旋转、零/180°轴角、反射矩阵拒绝、私有读取访问故障和同帧不一致、重复/过期/未来帧、生产者重启和重获。
